# Particle Shaper AI

## Description
A real-time interactive 3D particle system controlled using hand gestures via MediaPipe and rendered using Three.js.

## Features
- Real-time hand tracking
- Gesture-based particle scaling
- Multiple 3D shape morph targets
- Smooth particle transitions
- Customizable particle color

## Tech Stack
- Three.js
- MediaPipe Hands
- WebGL
- JavaScript

## How to Use
1. Open index.html in browser
2. Allow camera access
3. Use hand gestures:
   - Open hand ? expand particles
   - Closed fist ? contract particles

## Future Improvements
- Mobile optimization
- More gesture controls
- Preset saving
- Performance optimization (GPU instancing)
